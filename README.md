# Копилка

Личный учёт финансов для iPhone. Работает как приложение с экрана «Домой», без регистрации и без сервера: все данные хранятся на телефоне.

**Открыть:** https://yadimati.github.io/kopilka/

## Возможности

**Счета и валюты**
- Счета в любых валютах и криптовалютах (BTC, ETH, USDT, TON, SOL и свои монеты)
- Курсы подтягиваются сами: фиат по ЦБ РФ, крипта с CoinGecko (запасной источник — Binance); можно задать курс вручную
- Общий итог в выбранной основной валюте; большие суммы показываются компактно (1,24 млн ₽)
- Типы счетов: карта, наличные, накопительный, вклад, цель, криптокошелёк, биржа и другие
- **Цели** — сумма и срок, прогресс кольцом вокруг иконки
- **Накопительные счета и вклады** — ставка в год или в месяц и день начисления; в этот день Копилка спрашивает, пришли ли проценты, и записывает их одним касанием
- Правка текущего баланса: разница записывается корректировкой и не портит статистику трат

**Записи**
- Перетащите счёт на категорию — расход; источник на счёт — доход; счёт на счёт — перевод. Или просто тап по категории
- Сумма в любой валюте: потратил доллары с рублёвой карты — Копилка пересчитает по курсу, а сумму списания можно поправить
- Подкатегории, дата, время и комментарий
- **«Записать и ещё»** — несколько трат подряд, не закрывая окно; отмена последней записи
- **Разделение чека** по нескольким категориям
- **«Не потратил»** — запишите покупку, от которой отказались, и в конце месяца увидите, сколько сберегли

**Операции и анализ**
- Поиск по названию, сумме, счёту и комментарию, фильтры по периоду, типу, счёту и категории
- Карточка операции с мини-аналитикой по категории, «Повторить сегодня» и редактирование
- Анализ месяца по категориям и подкатегориям, по источникам дохода, сравнение с прошлым месяцем
- Итоги месяца с предложением отложить сэкономленное на цель
- Экспорт операций в Excel (CSV)

**Долги и напоминания**
- Кому дал и у кого взял, частичные возвраты, сроки
- Напоминания о платежах и подписках с добавлением в Календарь iPhone

**Главная под себя**
- Режим «Изменить»: порядок счетов, источников и категорий перетаскиванием, правка и удаление

**Сохранность данных**
- Бэкап в файл, зашифрованный паролем (AES-GCM)
- Облачная копия с шифрованием на телефоне: на сервер уходит только зашифрованный блок, открыть его можно только ключом восстановления
- Обновление в одно касание: перед ним Копилка сохраняет копию данных, а при сбое их можно вернуть
- Журнал событий приложения (без сумм и названий)
- Работает без интернета

## Установка на iPhone

1. Откройте ссылку выше в **Safari**.
2. Нажмите «Поделиться» → **«На экран Домой»**.
3. Запускайте Копилку с иконки.

> Данные в Safari и в установленной Копилке хранятся раздельно, поэтому ведите учёт в установленной версии.

## Технологии

- HTML, CSS и JavaScript (ES-модули) без фреймворков и сборки
- IndexedDB — хранение данных на устройстве
- Web Crypto API — шифрование (PBKDF2 + AES-GCM)
- Service Worker и Web App Manifest — установка и работа офлайн
- Cloudflare Workers + KV — сервер облачной копии (необязательно, см. `cloud-worker/DEPLOY.md`)
- Суммы хранятся целыми числами в минимальных единицах валюты (копейки, сатоши), чтобы не было ошибок округления

## Структура

| Файл | Что внутри |
|---|---|
| `index.html`, `styles.css` | каркас и оформление |
| `app.js` | запуск, отрисовка вкладок, события |
| `state.js` | данные, расчёт балансов и итогов |
| `home.js` | главная, перетаскивание, «Изменить», проценты, итоги месяца |
| `entry.js` | окно записи операции |
| `ops.js` | список операций, поиск, карточка |
| `analytics.js` | анализ месяца |
| `debts.js` | долги и напоминания |
| `settings.js` | настройки, счета, бэкапы, экспорт |
| `onboarding.js` | первое знакомство |
| `updates.js` | проверка и установка обновлений |
| `money.js` | валюты, суммы, курсы |
| `crypto.js`, `cloud.js` | шифрование и облачная копия |
| `store.js` | хранилище и журнал |
| `config.js` | версия, ссылка на разработчика, адрес облака |
| `sw.js` | работа без интернета |

## Выпуск обновления

1. Поднимите `APP_VERSION` в `config.js`.
2. Впишите ту же версию и список изменений в `version.json`.
3. Поменяйте `VERSION` в `sw.js`.
4. Загрузите файлы в репозиторий — у пользователей появится кнопка «Обновить».
