# Облачная копия: как запустить сервер

Сервер нужен только для облачной копии. Без него Копилка работает полностью, просто пункт «Облачная копия» в настройках скрыт.

Сервер бесплатный — Cloudflare Workers. Банковская карта не нужна.

## 1. Хранилище
1. Зарегистрируйтесь на https://dash.cloudflare.com
2. Слева: **Storage & Databases → KV** (Workers KV) → **Create** (Create a namespace).
3. Название: `kopilka-backups` → Create.

## 2. Worker
1. Слева: **Compute (Workers) → Workers & Pages → Create → Create Worker** (шаблон Hello World).
2. Имя: `kopilka-cloud` → **Deploy**.
3. **Edit code** → удалите всё и вставьте содержимое `worker.js` из этой папки → **Deploy**.

## 3. Связать Worker с хранилищем
1. Откройте worker `kopilka-cloud` → **Settings → Bindings → Add → KV namespace**.
2. Variable name: `BACKUPS` (именно так, большими буквами), namespace: `kopilka-backups` → Save / Deploy.

## 4. Подключить к Копилке
1. Скопируйте адрес worker'а, вида `https://kopilka-cloud.ВАШ-ЛОГИН.workers.dev`. Откройте его в браузере — должно быть написано `Kopilka cloud: ok`.
2. В `config.js` впишите его: `export const CLOUD_URL = 'https://kopilka-cloud.ВАШ-ЛОГИН.workers.dev';`
3. Поднимите версию (см. README, «Выпуск обновления») и загрузите файлы на GitHub.

Названия пунктов в панели Cloudflare иногда меняются — если чего-то нет на месте, ищите по смыслу: KV, Workers, Bindings.

## Лимиты бесплатного тарифа
- 100 000 запросов в день к Worker;
- KV: 1 000 записей и 100 000 чтений в день, 1 ГБ места.

Копилка отправляет копию не чаще раза в 10 минут, так что одному пользователю это с огромным запасом (максимум ~144 записи в сутки).

## Безопасность
- Данные шифруются на телефоне ключом восстановления (PBKDF2 + AES-GCM) до отправки.
- Адрес копии на сервере — хэш от ключа, сам ключ на сервер не уходит.
- Владелец сервера видит только зашифрованные блоки и не может их прочитать.
